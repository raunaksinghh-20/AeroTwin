# AeroTwin

**AeroTwin** is a real-time drone monitoring and digital twin platform designed to provide a unified view of a drone's operational state, telemetry, and system health.

The platform combines a modern desktop dashboard with a **2D digital twin of the physical drone**, allowing users to visualize live flight parameters and understand the drone's current condition through an intuitive interface.

Built with **Tauri and React**, AeroTwin is designed to receive and process real-time telemetry from the drone through wireless communication such as **Wi-Fi/UDP**. The dashboard presents critical parameters including battery status, signal strength, sensor data, motion, and other flight-related information, while the digital twin provides a visual representation of the drone and its changing state.

### Key Features

- **Real-time Drone Telemetry** for monitoring live sensor and flight data
- **2D Digital Twin** representing the physical drone and its operational state
- **Interactive Dashboard** for centralized monitoring and visualization
- **Wireless Communication** using Wi-Fi/UDP for low-latency telemetry
- **Drone Health Monitoring** for tracking important system parameters
- **Desktop Application** built with Tauri for a lightweight native experience
- **React-based UI** designed for responsive and intuitive interaction
- **Extensible Architecture** allowing future integration of drone control, analytics, alerts, and additional sensors

AeroTwin aims to bridge the gap between the **physical drone and its digital representation**, providing operators with a real-time window into the drone's behavior, health, and performance.

> **AeroTwin: Connecting the physical drone to its digital world.**
